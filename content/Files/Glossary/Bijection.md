Something that is bijective or a bijection is a function between two sets such that each element of the second set is the image of exactly one element of the first set. Basically each element in Set A is paired with exactly one element in Set B and that element in Set B is only paired with that element in Set A.

Key point is that the function is invertible if it is bijective and it is bijective if it is invertible.
