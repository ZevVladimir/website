# Features

- Ability to have a completion bar for projects that have a set number of tasks
- Recurring tasks
    - Automatic due dates
- Creation of “blocks” within documents
    - Allows for very modular writing and easy restructuring
    - Should be easy to create, add, remove information from a block
    - Kinda like paragraphs that can be moved around but more customizable
    - Can select certain blocks to have separate word count
- Habit tracker
- Backups
    - To the cloud
    - Locally
    - Be able to restore work from backup files
- Auto-wiki links
	- Have a glossary of definitions 
	- Able to have latex symbols as well
	- Be able to click on a symbol or word and transfer to the corresponding file's definition/notes on it
	- Create templates for topics that you can select on a page by page basis such that that note will auto link those files as detected (or with a tab to confirm)
		- Template would allow for unique definitions depending on what you are writing about
- Scaling priorities
	- For longer term not super important tasks where you don't want to just keep pushing them back or not seeing them because their priority is too low
	- Can set a maximum priority that slowly gets scaled to the closer the deadline is
- Advanced grouping
	- Ability to group information by date, task it belongs to, a simulation run (what parameters changed, what the results were)
	- Maybe smart tagging?
