# Features

- Made up of hexagonal tiles
- Easy to connect and snap together
    - Magnets
- Able to light up
- Can communicate information through the tiles
    - Enough to know which tile is where
    - Which color to turn
- Indicate if a building has been placed on the tile
    - Weight sensitive?
    - Another magnetic sensor?
- Connected to a computer
    - Wireless would be cool but wired with a controller is fine
    - Can see a visualization of the tiles on the computer
    - Can control the colors of each tile
